ℹ️ Informações

Como Funciona:

  1. Fazer Login: Clique no botão para abrir navegador
  2. Salvar Credenciais: Sistema guarda email/senha de forma segura
  3. Automação: Login renovado automaticamente a cada 3 dias
  4. Publicação: Publica nos grupos 24/7 sem intervenção

🔒 Segurança:

  • ✅ Credenciais encriptadas (Fernet)
  • ✅ Cookies validados com timestamp
  • ✅ Dashboard apenas localhost (sem exposição na internet)
  • ✅ Notificações WhatsApp se algo falhar

📅 Cronograma:

  • 🔄 Renovação de Cookies: A cada 3 dias (3:00 AM)
  • 📢 Publicação Marketplace: A cada 10 minutos (9:00-22:00)
  • 📍 Publicação Grupos: 11:30, 17:00, 21:30 diariamente
  • ⏸️ Limite: Máx 30 grupos/dia (regra do Facebook)
