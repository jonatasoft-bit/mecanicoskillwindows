# Documentacao - Impar Automacoes

Este diretorio contem a documentacao completa do projeto.

- **README.md** - Overview detalhado do projeto
- **MECANICO-IMPAR-PROCEDIMENTOS.md** - Procedures e checklists tecnicas
- **CONFIGURAR-WEBHOOK-FACEBOOK.md** - Como configurar webhook Facebook
- **SETUP-CHECKLIST.md** - Checklist de instalacao

Alem de:
- **LEIA-PRIMEIRO.txt** - Instrucoes originais (fica na raiz de impar-automations)
- **GUIA_RAPIDO_V2.txt** - Guia rapido de instalacao

## Como Adicionar

1. Extraia o arquivo ZIP
2. Copie todos os arquivos do diretorio `docs/` do ZIP para este diretorio
3. Copie o arquivo `LEIA-PRIMEIRO.txt` para a raiz de impar-automations
